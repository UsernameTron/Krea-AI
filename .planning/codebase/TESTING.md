## Test Framework

```

## Test File Organization

**Location:**
- All tests co-located in a flat `tests/` directory at project root (`flux-krea/tests/`)
- Not co-located with source files; no `__init__.py` in `tests/`

**Naming:**
- `test_{module_name}.py` — mirrors the source module name exactly
  - `config.py` → `test_config.py`
  - `pipeline.py` → `test_pipeline.py`
  - `app.py` → `test_app.py`
  - `optimizers/metal.py` → `test_metal.py`
  - `optimizers/thermal.py` → `test_thermal.py`
  - `optimizers/neural_engine.py` → `test_neural_engine.py`
  - `optimizers/__init__.py` → `test_optimizers_init.py`
  - `utils/benchmark.py` → `test_benchmark.py`
  - `utils/monitor.py` → `test_monitor.py`
  - `utils/profiler.py` → `test_profiler.py`
  - `main.py` → `test_main.py`

**Structure:**
```
flux-krea/tests/
├── conftest.py              # Shared fixtures: test_config, mock_diffusers_pipeline, requires_mps

## Test Structure

**Suite organization — class-per-behavior grouping:**
```python
class TestFluxKreaPipelineInit:
    def test_init_none_level(self, test_config): ...
    def test_init_standard_level(self, test_config): ...

class TestLoadFallbackChain:
    """Test the MAXIMUM -> STANDARD -> NONE fallback chain in load()."""
    def test_maximum_falls_back_to_standard_on_error(self, test_config): ...
    def test_none_level_raises_on_error(self, test_config): ...
```

**Patterns:**
- One class per logical behavior group (not one class per source class)
- Test method names follow `test_{what}_{condition_or_result}` pattern
- No `setUp`/`tearDown` — pytest fixtures handle all setup
- No shared state between tests; each test is self-contained

**Local helper factories inside test classes:**
```python
class TestApplyStandardOptimizations:
    def _make_pipeline(self, test_config, mock_diffusers_pipeline):
        """Helper: configure a partially-loaded pipeline for method-level tests."""
        ...

class TestGenerate:
    def _ready_app(self):
        """App with pipeline loaded and ready."""
        ...
```
Private helper methods prefixed `_` used to DRY test setup within a class.

## Shared Fixtures (`tests/conftest.py`)

**`test_config` fixture:**
```python
@pytest.fixture
def test_config():
    """Create a FluxConfig with test-friendly defaults."""
    from config import FluxConfig
    config = FluxConfig()
    config.generation.width = 512
    config.generation.height = 512
    config.generation.steps = 4
    config.optimization_level = "none"
    return config
```
Used in every test that needs a config. Overrides dimensions and steps to minimize computation.

**`mock_diffusers_pipeline` fixture:**
```python
@pytest.fixture
def mock_diffusers_pipeline(monkeypatch):
    """Mock diffusers.FluxPipeline.from_pretrained to avoid loading the 24GB model."""
    mock_pipe = MagicMock()
    mock_pipe.to = MagicMock(return_value=mock_pipe)
    # ... method mocks ...
    fake_image = Image.new("RGB", (512, 512), color="red")
    mock_result = MagicMock()
    mock_result.images = [fake_image]
    mock_pipe.return_value = mock_result
    monkeypatch.setattr(diffusers, "FluxPipeline", MagicMock(from_pretrained=mock_from_pretrained))
    return mock_pipe, mock_from_pretrained
```
Critical fixture — prevents loading the 24GB FLUX model during any test. Uses `monkeypatch` for isolation.

**`requires_mps` marker (module-level, not a fixture):**
```python
requires_mps = pytest.mark.skipif(
    not torch.backends.mps.is_available(),
    reason="MPS not available",
)
```
Imported from `conftest` and applied to hardware-dependent tests. CI always runs with `-m "not requires_mps"`.

**Local fixtures in individual test files:**
Some test files define their own fixtures when they need module-specific setup not shared with other files:
- `test_neural_engine.py`: `config`, `optimizer`, `mock_pipeline` fixtures defined locally
- `test_profiler.py`: `test_config`, `mock_pipeline` fixtures defined locally (shadows conftest `test_config`)

## Mocking Strategy

**Framework:** `unittest.mock` — `MagicMock`, `patch`, `patch.dict`, `patch.object`

**What is always mocked:**
- `diffusers.FluxPipeline.from_pretrained` — prevents 24GB model download/load (via `mock_diffusers_pipeline` fixture)
- `gradio` — injected into `sys.modules` before app import (evaluated at import time as default parameter)
- `torch.mps.*` functions when testing MPS code paths on non-MPS hardware
- External subprocesses (`subprocess.run`) in thermal tests

**What is never mocked:**
- `FluxConfig` and its dataclass hierarchy — always instantiated for real
- `torch` itself (except specific MPS methods) — real torch used for dtype/device operations
- File I/O in `save_image` tests — real temp directories via `tempfile.TemporaryDirectory`

**Module-level mock injection for import-time side effects:**
`test_app.py` and `test_main.py` inject a gradio mock into `sys.modules` before importing the module under test, because `gr.Progress()` is evaluated as a default parameter value at import time:

```python
_mock_gradio = MagicMock()
_mock_gradio.Progress.return_value = MagicMock()
_mock_gradio.Blocks.return_value.__enter__ = MagicMock(return_value=MagicMock())
_mock_gradio.Blocks.return_value.__exit__ = MagicMock(return_value=False)
# ... more context manager mocks ...
sys.modules["gradio"] = _mock_gradio

# Now safe to import
from app import FluxWebApp
```

**`patch.object` for method-level isolation:**
Used to test individual methods without triggering their dependencies:
```python
with patch.object(p, "_load_at_level", side_effect=fake_load_at_level):
    p.load()

with patch.object(p, "_apply_standard_optimizations") as mock_std:
    p._load_at_level(OptimizationLevel.STANDARD)
mock_std.assert_called_once()
```

**`patch.dict` for optional imports:**
Used to simulate absent optional packages:
```python
with patch.dict("sys.modules", {"optimizers.metal": None}):
    result = get_optimizer(config)
assert "metal" not in result
```

**`patch.dict(os.environ, ...)` for environment variable tests:**
```python
with patch.dict(os.environ, {"FLUX_OPTIMIZATION_LEVEL": "maximum"}):
    config = get_config()
    assert config.optimization_level == "maximum"
```

## Test Markers

**`requires_mps`:**
- Defined in `tests/conftest.py` as a `pytest.mark.skipif` condition
- Registered in `pyproject.toml`:
  ```toml
  [tool.pytest.ini_options]
  markers = [
      "requires_mps: marks tests requiring Apple MPS (Metal Performance Shaders)",
  ]
  ```
- Usage: `@requires_mps` decorator on test functions
- CI always runs with `-m "not requires_mps"` — hardware-gated tests never run on GitHub Actions Ubuntu runners

## Common Test Patterns

**Testing that exceptions do NOT propagate (resilience tests):**
```python
def test_silent_when_both_offload_methods_fail(self, test_config, mock_diffusers_pipeline):
    mock_pipe.enable_model_cpu_offload.side_effect = RuntimeError("no")
    mock_pipe.enable_sequential_cpu_offload.side_effect = RuntimeError("no")
    p._apply_cpu_offload()  # Must not raise
```
Used extensively in optimizer and thermal tests to verify error swallowing.

**Testing fallback chains:**
```python
call_levels = []

def fake_load_at_level(level, progress_callback=None):
    call_levels.append(level)
    if level == OptimizationLevel.MAXIMUM:
        raise RuntimeError("max failed")

with patch.object(p, "_load_at_level", side_effect=fake_load_at_level):
    p.load()

assert OptimizationLevel.MAXIMUM in call_levels
assert OptimizationLevel.STANDARD in call_levels
assert p.is_loaded is True
```

**Testing async/threading behavior:**
```python
def test_background_load_success_sets_event(self):
    web_app._background_load()
    assert web_app._load_event.is_set()

def test_start_loading_daemon_thread(self):
    class CapturingThread(original_thread):
        def __init__(self, *args, **kwargs):
            super().__init__(*args, **kwargs)
            threads_started.append(self)
    with patch("app.threading.Thread", CapturingThread):
        web_app.start_loading()
    assert threads_started[0].daemon is True
```

**Testing single-iteration background loops:**
```python
def _run_one_iteration(self, tm, temp_value=55.0):
    def read_temp_once():
        tm._monitoring = False  # Stop after first read
        return temp_value
    with patch.object(tm, "_read_temperature", side_effect=read_temp_once):
        with patch("optimizers.thermal.time.sleep"):
            tm._monitoring = True
            tm._monitor_loop(interval=0)
```
The pattern: set `_monitoring = False` inside the side effect to break the loop after one iteration, then inspect state.

**Testing environment variable effects:**
```python
def test_env_var_override(self):
    with patch.dict(os.environ, {"FLUX_OPTIMIZATION_LEVEL": "maximum"}):
        config = get_config()
        assert config.optimization_level == "maximum"
```

**Validation error testing:**
```python
def test_width_must_be_multiple_of_64(self):
    config = FluxConfig()
    config.generation.width = 500
    with pytest.raises(ValueError, match="multiple of 64"):
        config.validate()
```
Always use `match=` parameter with `pytest.raises` to confirm the error message content.

**Real file I/O with temp directories:**
```python
def test_creates_output_directory_if_missing(self, test_config):
    with tempfile.TemporaryDirectory() as tmpdir:
        new_dir = Path(tmpdir) / "new_subdir"
        test_config.output.directory = str(new_dir)
        p.save_image(mock_image, "test prompt")
        assert new_dir.exists()  # Assert INSIDE context manager
```
Note: assertions made inside the `with` block to avoid temp dir cleanup race.
