## Optimization Architecture

Three levels defined in `flux-krea/config.py` `OptimizationLevel` enum, implemented in `flux-krea/pipeline.py`:

| Level | What it applies |
|-------|-----------------|
| `none` | Baseline `FluxPipeline` + CPU offload only |
| `standard` | MPS device placement + attention slicing + VAE tiling/slicing + `AttnProcessor2_0` |
| `maximum` | All of `standard` + `MetalOptimizer` (VAE autocast) + `ThermalManager` background thread |

Fallback chain: `maximum` → `standard` → `none` (with logged warnings at each step).
