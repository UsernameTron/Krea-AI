**`buildUserMessage(classifierResult)`** — Takes output from `classifyInput()`. Returns Anthropic user message content array:

```javascript
// D-07: archetype definition + raw input + generation instruction
const blocks = [];

if (classifierResult.archetype) {
  // Full archetype definition (Pattern 12: loaded at generation time, not import time)
  blocks.push({
    type: "text",
    text: `## Selected Archetype\n\n${JSON.stringify(classifierResult.archetype, null, 2)}`
  });
}

if (classifierResult.input_type === "domain" && classifierResult.archetypes) {
  // Domain match: include all archetypes in category for model to choose from
  blocks.push({
    type: "text",
    text: `## Archetypes in ${classifierResult.input_raw} category\n\n${JSON.stringify(classifierResult.archetypes, null, 2)}\n\nSelect the most fitting archetype OR create an original character inspired by this category.`
  });
}

blocks.push({
  type: "text",
  text: `## Scenario\n\n${classifierResult.input_raw}\n\nGenerate a complete Post Brief JSON.`,
  cache_control: { type: "ephemeral" }  // D-13: cache marker on last user block
});

return blocks;
```

For freeform input: only the scenario block (no archetype definition). The cache_control always goes on the LAST block.
