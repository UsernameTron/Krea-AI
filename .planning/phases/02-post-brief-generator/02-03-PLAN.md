Classification algorithm (ordered by priority):

1. **Exact match by id**: `rawInput.toLowerCase().trim()` matches an archetype `id` field exactly. Return `{ input_type: "archetype", input_raw: rawInput, archetype: fullArchetypeObject }`.

2. **Exact match by name**: `rawInput.toLowerCase().trim()` matches an archetype `name` field (case-insensitive, ignoring "The " prefix). Return same shape.

3. **Domain match**: `rawInput.toLowerCase().trim()` matches a category `id` (e.g., "leadership", "vendor", "internal-blocker", "contact-center", "healthcare-rcm"). Return `{ input_type: "domain", input_raw: rawInput, archetypes: [...allArchetypesInCategory], archetype: null }`.

4. **Fuzzy match**: If input is <= 3 words AND a substring of any archetype name or id (case-insensitive), return the first match as `{ input_type: "archetype", input_raw: rawInput, archetype: matchedArchetype }`.

5. **Freeform**: Everything else. Return `{ input_type: "freeform", input_raw: rawInput, archetype: null }`.

Implementation notes:
- Build a flat list of all archetypes at module load time (from categories[].archetypes[])
- Build a map of category ids for domain matching
- The word-count heuristic (step 4 vs 5) prevents long scenario descriptions from accidentally fuzzy-matching an archetype name
- Empty/whitespace-only input: throw `new Error("Input required: provide an archetype name, category, or freeform scenario")`

Also export `getAllArchetypesMeta()` that returns archetype metadata (id, name, category, signature_move, tell) WITHOUT traits — this is the Pattern 12 upfront-loading function (REQ-M-015 / REQ-X-032). Full archetype definitions are only returned when matched.
