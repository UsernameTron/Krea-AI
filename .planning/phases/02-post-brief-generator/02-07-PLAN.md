**`SAFETY_ERROR_CODES`** — object mapping error codes to descriptions:
```javascript
export const SAFETY_ERROR_CODES = {
  SAFETY_INDIVIDUAL_TARGET: "Content appears to target a specific real individual",
  SAFETY_PUNCHING_DOWN: "Content targets vulnerable groups or involuntary circumstances",
  SAFETY_REAL_PERSON: "Character appears to be a real person, not a fictional composite",
  SAFETY_HARMFUL_CONTENT: "Content contains potentially harmful instructions",
  BANNED_AI_VOICE_MARKER: "Content contains AI assistant voice markers",
  BANNED_CORPORATE_JARGON: "Content uses corporate jargon that Pete's voice avoids",
  COMPLETENESS_EMPTY_FIELD: "Required field has empty or placeholder content",
  COMPLETENESS_NO_PROPS: "Brief has no props (minimum 4 required)",
  COMPLETENESS_SHORT_BODY: "Post body is too short (minimum 100 characters)",
  COMPLETENESS_NO_HASHTAGS: "Post has no hashtags",
  VOICE_DRIFT_SARCASM: "Sarcasm slider deviates >0.3 from target 0.80",
  VOICE_DRIFT_CYNICISM: "Cynicism slider deviates >0.3 from target 0.85",
  VOICE_DRIFT_WARMTH: "Warmth slider deviates >0.3 from target 0.25"
};
```

**`validateBriefSemantic(brief)`** — returns `{ valid: boolean, errors: string[], warnings: string[] }`:

1. **Schema check first**: Call `validateBrief(brief)` from schema.js. If invalid, return immediately with schema errors.

2. **Safety checks** (hard failures — D-19: 0 retries):
   - Scan `character.name` against a list of known public figures (basic list: top 50 tech/business names). If match: error `SAFETY_REAL_PERSON`. Use a simple array of strings: ["Elon Musk", "Jeff Bezos", "Mark Zuckerberg", "Satya Nadella", "Tim Cook", "Sam Altman", "Jensen Huang", "Sundar Pichai", "Andy Jassy", "Sheryl Sandberg"]. This is a heuristic, not exhaustive.
   - Scan all text fields (post.body.text, post.headline.text, tweet_embed.text, props[].text) for indicators of targeting vulnerable groups: regex patterns for disability, mental health, homelessness, addiction, poverty mockery. Match phrases like "people with [condition] are", "homeless people", "addicts deserve", etc. Error: `SAFETY_PUNCHING_DOWN`.
   - Scan for direct targeting language: "you specifically", "@realhandle", etc. Error: `SAFETY_INDIVIDUAL_TARGET`.

3. **Banned phrase checks** (hard failures):
   - Import `banned_patterns.ai_voice_markers` from mirror_pete.v2.json. Check all text fields for case-insensitive substring match. Error: `BANNED_AI_VOICE_MARKER` with the matched phrase.
   - Import `banned_patterns.corporate_jargon` from spec. Check post.body.text and post.headline.text ONLY (props and tweet embed may use jargon satirically). Error: `BANNED_CORPORATE_JARGON` with matched phrase. Exception: jargon inside quotation marks is allowed (it's being quoted satirically).

4. **Completeness audit** (hard failures):
   - `post.body.text` must be >= 100 characters. Error: `COMPLETENESS_SHORT_BODY`.
   - `props` must have >= 4 items. Error: `COMPLETENESS_NO_PROPS`.
   - `post.hashtags` must have >= 1 item. Error: `COMPLETENESS_NO_HASHTAGS`.
   - No required string field may be empty string. Error: `COMPLETENESS_EMPTY_FIELD` with field path.

5. **Voice drift detection** (warnings, not failures — D-20):
   - Compare `voice.sarcasm` to target 0.80 — warn if |delta| > 0.3
   - Compare `voice.cynicism` to target 0.85 — warn if |delta| > 0.3
   - Compare `voice.warmth` to target 0.25 — warn if |delta| > 0.3
   - These go into `warnings` array, not `errors`.

Return: `{ valid: errors.length === 0, errors, warnings }`

Safety errors are BLOCKING (valid=false). Voice drift warnings are non-blocking (valid can still be true if only warnings).
