<objective>
Build the deterministic image prompt engine: foundation prompt loader (singleton), 4 scene templates, and the prompt builder that transforms any valid Post Brief into a Flux-compatible structured prompt object.

Purpose: This is the bridge between the Post Brief (text/data) and flux-krea (image generation). Every image prompt must begin with the foundation master prompt, include character/scene/props delta from the Post Brief, and append fidelity modifiers -- all without any LLM call.

Output: `buildImagePrompt(brief)` function that returns `{ positive_prompt, negative_prompt, parameters, composition_notes }`, 4 scene template JSON files, foundation loader, and a test harness proving determinism and correctness.
</objective>

    **prompt-builder.js** — The core deterministic builder (per REQ-M-031, REQ-X-071, D-04 through D-07):

    Export: `buildImagePrompt(brief)` — takes a validated Post Brief object, returns `{ positive_prompt, negative_prompt, parameters, composition_notes }`.

    Implementation (per D-05 concatenation order):

    1. **Foundation prefix**: `getFoundation().foundation_prompt.reusable_master_prompt` — trimmed, always first.

    2. **Character delta**: Build from `brief.character` fields:
       - `"{brief.character.avatar_prompt}, {brief.image_seed.subject_pose}, {brief.image_seed.mood} expression, {brief.image_seed.color_temperature} lighting"`

    3. **Environment**: Route by `brief.image_seed.scene_template` (per D-01):
       - If `scene_template` is one of the 4 known IDs, load the matching template JSON (use a Map or switch). Use `template.environment + ', ' + template.lighting + ', ' + template.camera`.
       - If `scene_template` is unrecognized, absent, or empty, use `brief.image_seed.environment` directly as the environment string (freeform pass-through per D-01).
       - Always also append `brief.image_seed.environment` after template environment to capture any brief-specific environmental details the LLM added.

    4. **Props with text** (per D-14, REQ-M-034): Iterate `brief.props`. For each prop, describe the object and its text content for Flux to render:
       - mug: "ceramic coffee mug with text '{prop.text}' printed on side"
       - whiteboard: "office whiteboard with handwritten text: {prop.text joined by ', '}"
       - nameplate: "desk nameplate reading '{prop.text}'"
       - business_card: "business card with text '{prop.text}'"
       - folder: "manila folder labeled '{prop.text}'"
       - sticky_note: "sticky note with handwritten text '{prop.text}'"
       - Other types: "{prop.type} with '{prop.text}' visible"
       - Include placement context: "on {prop.placement}" converted to natural language (right_hand -> "held in right hand", desk_left -> "on left side of desk", background_right -> "on wall in background right", etc.)

    5. **Composition directives** (per D-02, REQ-M-033): Always append:
       - "composition: subject positioned right of center, left 35-40% of frame kept clear as text_clear_zone for overlay, lower-right area reserved for tweet embed card overlay, bottom edge reserved for engagement bar overlay"

    6. **Fidelity modifiers** (per REQ-M-032): Select 15-20 modifiers from ultra-fidelity.json:
       - Pick 2 from resolution_render_engine
       - Pick 2 from sensor_optics
       - Pick 2 from lighting_atmospherics
       - Pick 2 from material_surface_fidelity
       - Pick 2 from color_science_grade
       - Pick 1 from post_processing_output
       - Pick 2 from scene_composition_environment
       - Pick 1 from background_layout_constraints
       - Selection: use deterministic index based on brief content hash (e.g., simple string hash of `brief.character.name + brief.image_seed.scene_template`) to pick consistent modifiers for identical briefs. Do NOT use Math.random() — determinism is required (REQ-X-071).

    Join all sections with ", " separator into `positive_prompt`.

    **negative_prompt** (per D-06):
    - Surface-text guards: "text, words, letters, signage, watermark, caption, subtitle, label" (prevents stray text outside prop surfaces)
    - Append all items from `ultra-fidelity.json.negative_safety_prompts` array
    - Append all items from `12k-modifiers.json.categories.negatives` array
    - Deduplicate and join with ", "
