    **engagement.js** (per REQ-M-022, D-10 through D-13) — Satirically calibrated engagement generator:

    ```javascript
    export function generateEngagement(brief, options = {}) { ... }
    ```

    Parameters:
    - `brief`: A valid Post Brief object (reads `brief.character`, `brief.voice`, `brief.image_seed.scene_template`)
    - `options.seed`: Integer for deterministic output, or null/undefined for controlled randomness (per D-13)

    Implementation:

    1. **Tier detection** (per D-10): Map archetype category to engagement tier. Since the Post Brief doesn't carry `category` directly, infer tier from contextual signals:
       - If `brief.image_seed.scene_template` is "office-executive" -> "c-suite"
       - If `brief.image_seed.scene_template` is "office-middle-mgmt" -> "middle-management"
       - If `brief.image_seed.scene_template` is "airport-hustle" -> "hustle-culture"
       - If `brief.image_seed.scene_template` is "call-center-floor" -> "support-ops"
       - Default (freeform/unknown): "middle-management" (safe middle ground)

    2. **Calibration bands** (per D-11):
       ```
       c-suite:          { min: 47,  max: 2400, comment_ratio: [0.008, 0.02], dominant: "Insightful", dominant_pct: [0.60, 0.75] }
       middle-management:{ min: 85,  max: 340,  comment_ratio: [0.03, 0.08],  dominant: null (flat),   dominant_pct: [0.20, 0.30] }
       hustle-culture:   { min: 200, max: 1800, comment_ratio: [0.01, 0.03],  dominant: "Celebrate",   dominant_pct: [0.45, 0.55] }
       support-ops:      { min: 30,  max: 120,  comment_ratio: [0.05, 0.12],  dominant: "Like",        dominant_pct: [0.35, 0.45] }
       ```

    3. **Seeded random number generator**: Implement a simple deterministic PRNG (e.g., mulberry32 or a simple LCG) seeded from `options.seed`. When seed is null, use `Math.random()`. This ensures identical seed = identical output.

    4. **Reaction count**: Generate within tier's [min, max] range using the PRNG. Apply tone modifier: if `brief.voice.satirical_intensity >= 4`, bias toward upper 40% of range (high satire = more engagement because people can't tell it's satire).

    5. **Reaction type distribution** (per D-12):
       - LinkedIn types: "Like", "Celebrate", "Insightful", "Love", "Funny", "Support"
       - Set dominant reaction per tier. Allocate dominant_pct to dominant type.
       - Distribute remainder across other types (excluding Funny for non-dominant).
       - **Funny suppression**: Funny is always < 5% of total (per D-12 — "the satire is funnier when characters don't know they're being laughed at"). Even for middle-management "flat" distribution, cap Funny at 4%.
       - For middle-management (flat distribution): each type gets 15-20% except Funny capped at 4%.
       - Round individual type counts to integers, adjust to match total.

    6. **Comment count**: `Math.round(reactionCount * randomInRange(comment_ratio[0], comment_ratio[1]))`.

    7. **Dominant reaction**: The type with the highest count.

    8. **Return object**:
       ```javascript
       {
         reactions: {
           count: 247,
           types: ["Like", "Celebrate", "Insightful", "Love", "Funny", "Support"],
           distribution: { Like: 52, Celebrate: 68, Insightful: 62, Love: 38, Funny: 8, Support: 19 }
         },
         comments: 14,
         dominant_reaction: "Celebrate"
       }
       ```
       Note: The `distribution` field is an extension over the Post Brief schema (which only has `types` as string array). The distribution provides exact counts for the compositor. `types` is the list of reaction types that have > 0 count (for schema compatibility).
