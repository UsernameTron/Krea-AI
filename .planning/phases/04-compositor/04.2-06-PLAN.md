  <name>Task 3: Author linkedin-post.html template (pixel-accurate LinkedIn mimic)</name>
  <files>mirror-post/src/compositor/templates/linkedin-post.html</files>
  <action>
    Create `mirror-post/src/compositor/templates/linkedin-post.html` — a single self-contained HTML document that renders a LinkedIn post at 1920x1080.

    **Document shell:**
    - `<html>` with no external scripts, no remote stylesheets
    - `<meta charset="UTF-8">`
    - `<title>LinkedIn Post</title>`
    - Single `<style>` block with all CSS

    **@font-face declarations (at the top of the style block):**

    ```css
    @font-face {
      font-family: 'Inter';
      src: url('../fonts/Inter-Regular.ttf') format('truetype');
      font-weight: 400;
      font-style: normal;
    }
    @font-face {
      font-family: 'Inter';
      src: url('../fonts/Inter-SemiBold.ttf') format('truetype');
      font-weight: 600;
      font-style: normal;
    }
    @font-face {
      font-family: 'Inter';
      src: url('../fonts/Inter-Bold.ttf') format('truetype');
      font-weight: 700;
      font-style: normal;
    }
    ```

    **Root styling:**
    - `html, body { margin: 0; padding: 0; width: 1920px; height: 1080px; font-family: 'Inter'; }`
    - NO `system-ui`, NO `sans-serif` fallbacks. Puppeteer must fail loudly if Inter does not load, not silently fall back to Helvetica.
    - Body background: `#F3F2EF` (LinkedIn page background).

    **LinkedIn brand palette (use these exact values — do not approximate):**
    - Primary blue: `#0A66C2`
    - Deep navy: `#234C78`
    - Twitter/X blue (for embedded tweet links): `#1D9BF0`
    - Page background: `#F3F2EF`
    - Card border: `#D9D9D9`
    - Secondary text: `#666666`
    - Primary text: `#1D2226`

    **Layout zones (approximate — executor fine-tunes for pixel fidelity):**

    1. Top nav bar (full width, ~56px tall) — LinkedIn logo (from `./assets/linkedin-logo.svg`), search box placeholder, nav icons.
    2. Main card (centered, ~800px wide) — white background, 1px `#D9D9D9` border, 8px radius.
    3. Profile bar — avatar placeholder, `{{profile_name}}` bold, verified badge from `./assets/verified-badge.svg`, `{{profile_title}}` muted, timestamp.
    4. Post label strip — `{{post_label}}` (e.g., "Post").
    5. **HERO_ZONE rectangle** — reserved block where scene PNG will be composited. This element must be styleable/positionable but its PIXEL COORDINATES relative to the 1920×1080 canvas are what `hero-zone.js` exports. Suggested: a `<div id="hero-zone">` with fixed width/height, the compositor overlays the scene PNG via sharp AFTER Puppeteer renders.
    6. Headline — `{{headline}}` in 700 weight, ~32px.
    7. Body — `{{body}}` in 400 weight, ~18px, preserved line breaks (use `white-space: pre-wrap`).
    8. Hashtags — `{{hashtags}}` in `#0A66C2` primary blue.
    9. Embedded tweet card — a sub-card with:
       - `{{mini_profile_name}}` bold
       - `{{mini_handle}}` muted
       - `{{mini_body}}` body text
       - `{{mini_hashtags}}` in `#1D9BF0`
    10. Engagement bar — reaction emojis (like/celebrate/support SVGs), `{{reaction_count}}`, `{{comment_count}}` comments.

    **Required {{placeholder}} tokens (the compositor will substitute these before render):**

    ```
    {{profile_name}}
    {{profile_title}}
    {{post_label}}
    {{headline}}
    {{body}}
    {{hashtags}}
    {{mini_profile_name}}

    {{mini_body}}

    {{comment_count}}
    ```
