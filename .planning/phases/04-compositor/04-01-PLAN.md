Sharp composite call structure:
```javascript
const result = await sharp({
  create: { width: 1920, height: 1080, channels: 4, background: { r: 255, g: 255, b: 255, alpha: 1 } }
})
  .composite([
    { input: heroResized, top: 124, left: 0 },
    { input: topNav.buffer, top: 0, left: 0, raw: { width: 1920, height: 52, channels: 4 } },

    { input: engagementBar.buffer, top: 948, left: 0, raw: { width: 1920, height: 132, channels: 4 } },
  ])
  .png({ compressionLevel: 9, adaptiveFiltering: false })
  .toBuffer();
```
