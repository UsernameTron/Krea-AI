**DECISION 2 — Schema v2 bump (Recommended chosen)**

Advisor C's three sub-recommendations all accepted as a bundle:

- **C1:** `image_seed.environment` / `subject_pose` / `mood` / `color_temperature` **survive as optional nullable overrides** in the v2 schema. Default source of truth is the variant template; these fields let the Post Brief override the template on a per-post basis. Null = use template default.
- **C2:** Placeholder substitution (`[Profile Name]`, `[Board Title]`, etc.) happens at **Phase 5 render time** — not Phase 2 generation time, not Phase 4 overlay time. Phase 5 reads the Post Brief fields and substitutes into the variant prompt template before diffusion.
- **C3:** Post Brief carries the generated scene PNG path via a new **`image_output.scene_png`** field. Phase 4 reads this path directly; no cache lookup required. The field is populated by Phase 5 after scene generation completes.
- **Migration:** 4 existing Post Brief v1 fixtures must be migrated to v2. Bump `schema_version` field from `"1.0"` to `"2.0"`.

**This RESOLVES D-NEW-06** from `04-CONTEXT-RESET.md` (was "operator decision pending"). V2 bump confirmed.
